# BookEase – Client Appointment System

BookEase is a full-stack appointment management platform for service-based businesses such as hair salons and barber shops.

## Planned Stack
- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Prisma
- Tailwind CSS
- JWT Authentication

## Planned Features
- Authentication
- Client management
- Service management
- Appointment scheduling
- Appointment status tracking
- Dashboard
- Mock reminder integrations

## Local Setup

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
